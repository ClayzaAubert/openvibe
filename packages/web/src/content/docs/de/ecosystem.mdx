---

Eine Sammlung von Community-Projekten, die auf OpenVibe basieren.

:::note
Möchten Sie Ihr OpenVibe-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openvibe](https://github.com/awesome-openvibe/awesome-openvibe) und [openvibe.cafe](https://openvibe.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
