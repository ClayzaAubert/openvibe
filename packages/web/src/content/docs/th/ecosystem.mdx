ชุดโครงการชุมชนที่สร้างขึ้นบน OpenVibe

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenVibe ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-openvibe](https://github.com/awesome-openvibe/awesome-openvibe) และ [openvibe.cafe](https://openvibe.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
