Una colección de proyectos comunitarios construidos en OpenVibe.

:::note
¿Quieres agregar tu proyecto relacionado con OpenVibe a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-openvibe](https://github.com/awesome-openvibe/awesome-openvibe) y [openvibe.cafe](https://openvibe.cafe), una comunidad que agrega el ecosistema y la comunidad.
